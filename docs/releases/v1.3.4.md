发布日期：2026-10-30

## 下载哪一个

| 你是 | 下载 | 用途 |
| --- | --- | --- |
| 普通用户 | `WendaoResearch-v1.3.4-User.zip` | 解压后双击 `WendaoResearchV3.exe`，无需 Python |

## 本版变更

### 导航不再跳回页首

- 点击任意侧栏菜单时，程序会记住当前阅读位置，并在目标页面加载后恢复；不再每次回到顶部。
- 侧栏自身的滚动位置也会保留，长导航列表不会重新回到第一项。
- 只在同一标签页内、15 秒内的正常左键跳转生效；新标签页、外链、下载链接和页内锚点不受影响。
- 菜单跳转、表单提交与浏览器前进后退的行为保持原样。

### 工作台：EG 实验 → 通用DIY实验

- 默认学习领域 `EG 实验` 更名为 `通用DIY实验`，说明改为“任意方向的实验批次台账：条件、指标与结论自由填写”。
- 实验模块的副标题、启动任务描述、架构文档与自检样例同步更新。
- 升级只重命名仍叫 `EG 实验` 的出厂领域；用户自己改过的领域名保持不变。

### 实验台账改造为通用型

- 表单不再要求配比、水胶比、压实、电压窗、比电容等特定场景字段，改为两个自由文本区：
  **实验条件** 与 **观测指标**，每行一条，学科与单位由使用者自己定义。
- 列表只展示样品、日期、条件、指标、状态与操作；导出 CSV 同样只包含通用列。
- 数据库新增 `conditions`、`measurements` 两列（schema v5）。旧记录的专用数值不会被删除，
  首次升级时会自动归并成一段“旧版字段：…”文本，仍可阅读和继续编辑。
- 迁移前自动创建数据库快照；迁移失败会整体回滚。

### 首页文案精简

- 删除首页山门中的长段自述：
  “科研系统的目标不是让我完成更多任务，而是让我不必每天重新决定如何学习……”
- 诗句、日期、境界与连续天数保留，版面不再被长段落占满。

## 升级注意

- 数据目录不变：安装版仍是 `%LOCALAPPDATA%\WendaoResearchV3`；更新只替换 EXE。
- 首次启动会执行 schema v5 迁移；升级前快照位于 `instance/migration_snapshots/`。
- 1.3.3 及更早版本需要手动安装一次 1.3.4；之后可走应用内更新。
