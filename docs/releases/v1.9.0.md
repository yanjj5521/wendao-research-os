## 新功能：条目撤回（M1：自撤回 + 快照 + 日志）

依据 `docs/designs/upload-withdrawal.md` 实施第一期。上传/新建的资料发现内容有误时：

- **入口**：条目详情页新增"内容有误？申请撤回"面板——选错误类型（重复上传/传错文件/
  归档错位/内容有误/涉密隐私/其他）+ 填写至少 10 字说明；
- **自动判级**：距创建 ≤24 小时 → **自动执行**（条目下架）；超出窗口 → 转入"待确认"记录，
  由本人在知识库页显式确认执行（个人端无独立管理员，确认即自任审核，全程留痕）；
- **快照**：执行前自动保存条目完整 JSON 快照（`entry_revisions`）+ 附件文件副本；
- **日志**：`upload_withdrawals` 状态机（pending_review/approved/cancelled/obsolete）+
  `activities` 日志（withdraw / withdraw_restore）；
- **恢复**：知识库页"撤回记录"面板可对已撤回条目**一键从快照恢复**；
- 同一条目同时只允许一张处理中的撤回单；重复撤回/状态冲突均有明确提示。

改动位置：`services/withdrawal.py`（新，核心逻辑）、`core/schema/personal.py`（schema v6：
`upload_withdrawals`/`entry_revisions` 两张新表）、`core/migrations.py`（v6 迁移，老库自动升级
并先做迁移前快照）、`web/routes/library.py`（4 条新路由 + 详情页/列表上下文）、
`templates/entry.html` + `templates/library.html`（UI）。

## 项目结构精简

删除 `.runtime/` 下 **42 项**一次性补丁脚本与测试残留（约 25 MB）：
`patch_*.py × 19`、`fix_*.py`、`bump_*.py`、`extract_*.py`、`add_*_test.py`、`update_*.py`、
`clean_hub_copy.py`、`registration_matrix.py` 等一次性脚本（效果均已提交进正式代码），
以及 `extracted-headnet.exe`（22 MB，可从发布包再生）、`execheck-v183/`、`selfcheck-v183/`、
`headnet-manager-center4/`、`registration-http-*` 临时目录、空日志与 `write-test.lock`。

**保留**（活动数据，绝不触碰）：`.runtime/instance|storage|user_config|logs`。
同时清理全仓 `__pycache__`/`.pytest_cache`/`.ruff_cache`。

**依赖关系核查结论**：根级脚本（self_test/hub_self_test/online_integration_test/run_hub/
desktop_pet/desktop_shell）均被 CI 工作流引用；`tools/` 全部工具被构建链引用；
`mobile/`、`assets/` 被 CI 与图标构建引用——无一冗余，全部保留。
