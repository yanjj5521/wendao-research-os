# 问道科研 1.12.9

发布日期：2026-11-07

本版主题：**给应用本体瘦身**（安装包从 70 MB 量级显著下降）、界面文案去过度解释、导航入口整合。

## 一、体积压缩：从依赖下手

| 改动 | 说明 | 效果 |
| --- | --- | --- |
| 移除 **PyMuPDF** | 全项目只有"文献精读·图表抽取"用到它，而它给 EXE 带来数十 MB 的 libmupdf。已用项目既有依赖 **pypdf** 重写抽取（保留"≥12KB 内嵌位图、去重、上限 12 张"的全部原有规则） | EXE 体积大幅下降（见下方实测） |
| 移除 **openpyxl** | 全项目零调用（`grep Workbook(/load_workbook)` 无结果），纯遗留声明 | 依赖表 −1 |
| 收紧打包排除清单 | `unittest`、`pydoc_data`、`tkinter`、`fitz`、`pymupdf`、`openpyxl` 不再进入 EXE | 减少隐性打包 |

**功能性取舍（如实说明）**：以矢量图为主的论文，无法再由服务端把页面渲染成图片；此类论文请用系统截图后从「上传资料」入库。内嵌位图图表（扫描件、照片型图表）的抽取行为与旧版一致。页面提示已同步更新。

## 二、界面文案：删过度解释

对 settings / online / cultivation / plans 等页的"教学式"说明做了精简，例如：

- "关闭只隐藏入口；修为与境界照常累计，秘境试炼不受影响。" → "关闭只隐藏入口，数值照常累计。"
- "所有选择只保存在本机；可以丰富，也可以一键保持安静。系统会尊重操作系统的减少动态效果设置。" → "只保存在本机；跟随系统减少动态效果设置。"
- 删除两条历史迁移说明（v8 包导入、卡片生效时机）。

安全与隐私边界提示（密钥只存本机、公网必须 HTTPS、共享码不含密钥等）**全部保留**。全站说明性文字再降约一成，页面只留"必要的提示"。

## 三、导航整合

「写笔记」「上传资料」不再单独占导航位——知识库页顶部本就有「＋ 新记录」「↑ 上传文件」两个入口，功能入口合一、层级更浅：

- 知识组导航从 6 项 → 4 项（知识库 / 全库检索 / 交付文件夹 / 联网找论文）；
- 两个页面与路由**原样保留**，书签直达不受影响；
- 需要单独入口的，可在「设置 → 调整导航」重新打开。
