## 一、境界自动同步

不用再记着点按钮：

- **联机成功**（保存并联机）后自动推一次；
- 点「立即同步」时顺带推一次，并在提示里写明同步成了什么境界；
- **启动时**后台补推一次，失败静默，不阻塞启动；
- 节流规则：境界名/序号/修为**没变**就不推；距上次不足 **6 小时**也不推；
- 手动按钮保留，含义改为「强制推一次」。

只推 `realm_name / realm_index / cultivation` 三项快照，不改中心任何数据。

## 二、高速下载：测速选线 + 双线并发

原来是"一条连接从头拉到尾"。现在：

1. **先测速**：对直连与两个镜像各拉 512 KB，量出速度、总大小、是否支持分段；
2. **选最快线路**，并按服务端是否支持 `Range` 决定策略；
3. **2 路并发分段**下载（实测最快），拼回后统一 SHA-256 校验；
4. 任一段失败或哈希不符 → 删掉临时文件，回退到可续传的单连接下载。

本机实测（同一 69.7 MB 包、同一代理）：

| 方式 | 耗时 | 速度 |
| --- | --- | --- |
| 单连接 | 8.9 s | 7.8 MB/s |
| **2 路并发** | **5.2 s** | **13.3 MB/s** |
| 4 路并发 | 5.9 s | 11.9 MB/s |

（4 路反而慢，是对端按连接限速；所以定为 2 路，而不是越多越好。）

中心取包（同行会版本中心）与 GitHub 更新现在共用这套实现。
