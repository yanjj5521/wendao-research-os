## 跨局域网与 VPN 连接

- 同行会继续监听 `0.0.0.0`，同时接受有线网卡、无线网卡和 VPN 虚拟网卡连接。
- 个人端“同行会”页面现在会列出所有检测到的成员入口，并标注有线局域网、无线局域网、局域网、VPN/虚拟局域网和虚拟网卡，不再只猜测一个地址。
- 管理控制台新增“成员连接地址”面板，可查看当前注册基址并填写固定 VPN、Tailscale、WireGuard 或 HTTPS 公网入口。
- 邀请码的“打开注册页”现在生成完整可分享 URL，不再使用管理员本机的 `127.0.0.1` 地址。
- 支持 Tailscale/WireGuard 常见的 `100.64.0.0/10` CGNAT HTTP 地址，以及 `.ts.net` 等内部域名。
- `run_hub.py` 增加高级 `--host` 绑定参数；默认仍为 `0.0.0.0`。
- 在线联机集成测试会实际通过非回环地址访问中心 `/health`，验证成员网络入口真实可监听。
- 后台启动增加端口预检与 `/health` 探活；端口被占用或监听失败时直接报错，不再误报“已启动”。

## 连接边界

- 程序不会自行创建 VPN、穿透 NAT 或修改路由器端口映射。
- 跨局域网场景需要所有成员加入同一个 VPN 虚拟网络，且 VPN 允许成员访问中心主机和 TCP 端口。
- Windows 防火墙必须允许该端口；公网 HTTP 不安全，公网入口必须使用 HTTPS。
- 同一房间内可优先使用有线或无线局域网地址。

详细配置与故障排查见 `docs/HUB_NETWORK.md`。
