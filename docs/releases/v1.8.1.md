# 问道科研 1.8.1

## 重点修复

- 修复同行会旧数据库仍把资产、邀请码、审计等表关联到废弃 `hub_users` 的问题。升级后会自动执行 schema v4 迁移，旧账号与邀请码保留，注册不再因外键错误整笔回滚。
- 修复注册失败被统一误报为“账号信息冲突”。现在会区分用户名/邮箱重复、旧库关联结构异常和其他数据库错误，并明确提示邀请码是否已扣除。
- 注册邮箱明确为可选字段，留空也能正常创建账号。
- 管理控制台新增邀请码删除按钮，仅管理员可操作、带 CSRF 校验并写入审计日志；删除邀请码不影响已有账号。
- 同行会所有页面接入滚动位置保持：左栏、顶部导航、操作按钮和表单跳转后会回到原位置；与个人端共用位置记录。
- 修复管理员改密并删除一次性凭据后，冻结版 `--mode team --self-check` 仍误判失败的问题；自检现在也会检查旧身份外键与数据库完整性。

## 升级说明

- 首次启动 1.8.1 时，同行会数据库会自动从 schema v3 升级到 v4。
- 迁移前会创建一致性快照，位于数据目录的 `instance/migration_snapshots/`。
- 迁移会保留有效账号与邀请码；已失去对应账号的旧资产/资料记录会被清理，无法关联账号的审计或创建人字段会置空。
- 不需要删除或重建现有 `hub.db`。

## 验证

- Hub schema v4 迁移专项测试通过。
- 使用实例 `TD7Z5UU5` 数据库副本完成真实注册流程：空邮箱成员创建成功、邀请码正确扣减、`foreign_key_check` 为 0。
- 注册、邀请码删除权限/CSRF、滚动保持和全量回归测试通过。
