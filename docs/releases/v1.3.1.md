# 问道科研 1.3.1

发布日期：2026-10-29

## 下载哪一个

| 你是 | 下载 | 用途 |
| --- | --- | --- |
| 普通用户 | `WendaoResearch-v1.3.1-User.zip` | 解压后双击 `WendaoResearchV3.exe`，无需 Python |
| 同行会管理员 / 开发者 | `WendaoResearch-v1.3.1-Admin-Dev.zip` | 上传成员更新、重建程序、查看源码与测试 |

两个包版本号相同；管理端界面只由登录身份决定，不需要另装程序。

## 本版变更

### 全部已实现功能默认可达

- 侧栏默认显示全部 30 个功能条目，不再只保留九项；低频功能改为用户自行收起。
- 补回三个从未登记进导航的功能：**实验台账、数据集、模拟案例**。
- 趣味层（成就图鉴、炼丹炉、我的洞府、挂机静修）默认开启，仍可在设置中关闭。
- 升级时只替换“未改动的旧九项出厂布局”；已自定义的顺序、名称与可见性逐字保留，
  新增的三个入口追加为可见。

### 单一 EXE 入口

原来的 6 个 CMD 与打包目录里的团队中心 CMD 全部收束进程序：

```text
WendaoResearchV3.exe              个人端
WendaoResearchV3.exe --mode team  同行会中心
WendaoResearchV3.exe install      安装并创建快捷方式
WendaoResearchV3.exe shortcut     只重建快捷方式
WendaoResearchV3.exe diagnose     自检
WendaoResearchV3.exe version      版本与数据目录
```

源码模式的子命令完全一致：`python run_local.py <命令>`。

### 没有同行会也能更新

- “更新与同步”新增 **检查 GitHub 新版本**：直连公开仓库的 `releases/latest`，
  校验 `SHA256SUMS.txt` 后复用同一套备份、替换与回滚流程。
- 只读取公开发布，不上传任何本地资料，也没有后台轮询；未联网时只提示失败，不影响使用。
- 手动下载 User 包替换 EXE 仍然有效，两条路径效果一致。

### 修复

- 诊断命令改为使用临时数据目录，不再可能写入真实数据库。
- 安装脚本随 EXE 内置，安装不再依赖外部 PowerShell 文件路径。
- 同行会管理端停用成员不再触发数据库派生列错误，且不允许停用管理员。

## 升级注意

- 数据目录不随版本改变：安装版仍在 `%LOCALAPPDATA%\WendaoResearchV3`；
  更新只替换 EXE，数据库、论文、笔记、附件与个人配置原样保留。
- 从 1.3.0 升级会新增三个导航入口；如果你此前手动隐藏过某些功能，隐藏状态不会被改动。
- 同行会成员可在“同行会 → 更新与同步”检查更新；管理员需先在版本中心上传
  `app/Team-Update.zip`。

## 校验

```powershell
Get-FileHash .\WendaoResearch-v1.3.1-User.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```
