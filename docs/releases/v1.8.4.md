## 新增：手动下载包完整性校验

针对“从浏览器下载更新包后被截断、替换 EXE 后启动报
`ModuleNotFoundError: No module named 'pydantic_core._pydantic_core'`”的问题（根因是
PyInstaller onefile 的包归档附在 EXE 尾部，截断下载正好丢掉这一段），在
**设置 → 更新与同步** 新增“手动下载了更新包？先校验完整性再替换”工具：

- 选择下载的 `.zip` → 程序流式计算 SHA-256（上限 900 MB）；
- 可粘贴**预期的 SHA-256 或 SHA256SUMS.txt 中的整行**，自动比对：
  一致 → “文件完整”；不一致 → 明确提示“请勿替换 EXE，重新下载”；
- 不填预期则给出计算值，供与发布页 `SHA256SUMS.txt` 人工比对。

改动位置：`features/sync.py::online_verify_package`（路由）+ `templates/online.html`（面板）。
测试：`tests/test_verify_package.py`（正确哈希/整行粘贴/错误哈希拒绝/空预期四种场景 +
页面入口存在性）；路由清单与 self_test 已同步。
