## 一、静修壁纸换不掉：两个单选组在互相覆盖

内置壁纸与自定义壁纸用了两个不同的 `name`（`builtin_wallpaper` / `custom_wallpaper`），
浏览器会把两组都提交；服务端先应用内置、再应用自定义——**后处理的自定义永远赢**。
所以选过一张自定义壁纸后，再点任何内置壁纸都"没反应"。

修复：两组合并为一个 `wallpaper` 字段，值带前缀（`builtin:dawn` / `custom:xxx.webp`），
互斥且后选生效；旧字段仍兼容，只在没有新字段时兜底。回归用例覆盖"自定义 → 内置 → 自定义"三次切换。

## 三、"下一步？"展不开：换成按钮驱动

原来用 `<details>`，与全局 `summary` 样式叠加后点击无反应。现在改为
**`<button aria-expanded>` + `hidden` 表单 + 少量 JS**，并补上展开后自动聚焦输入框、
`＋` 旋转 45° 的反馈。不依赖浏览器对 `details` 的实现差异。
