## 本版新增

### 红包分为指定红包与群发红包

- **指定红包**：指定一位成员，发出即到账，不能发给自己。
- **群发红包**：全群 24 小时可抢，2–20 份；**发送者本人也可以参与抢**，不再被排除。
- 群发红包仍按二倍均值随机、最后一份兜底；抢完 `finished`，到期未抢完原额退回。
- 坊市页面文案、按钮与记录类型已同步区分；发送者抢自己的红包会显示“抢红包（我发的）”。

### 聊天表情面板

- 聊天输入框上方新增 24 个常用表情：😀 😄 😊 🥹 😭 😅 👍 🙏 💪 ✨ 🌿 🧪 📚 🔍 💡 🔥 🎉 ☕ 🌙 ⭐ 🧠 📌 ✅ 🧧。
- 点击表情会插入到光标位置，不会覆盖已输入文字；仍走原有的即时发送 / 2 秒轮询链路。

### 交易材料扩展

新增 12 种可流转资产，按四类分组：

| 类别 | 材料 |
|---|---|
| 基础 | 修为、灵石、灵木 |
| 灵草 | 聚气草、凝露花、赤霞芝 |
| 法宝 | 青锋剑、护心镜、乾坤袋 |
| 天地灵物 | 玄铁、星砂、太初石 |

- 所有红包、交换、福利发放的下拉框按类别分组显示。
- 新材料有各自单次流转上限；新注册成员的“开宗礼包”增加少量聚气草、凝露花、太初石。
- 旧账户不受影响，新资产余额从 0 开始。

### 洞府界面升级

- **建筑可点击进入内部**：藏经阁、炼丹房、炼器坊、灵植园各有独立内部页，包含室内主题、可做的事、升级入口与最近修建记录。
- 建筑卡片整体改为链接，点击卡片直接进入对应内部；升级操作移到内部页，避免误点。
- **建筑图标从 40px 放大到 64px**，建筑名 17px、描述 11px；“点击进入内部”提示更明确。
- 洞府整体排版放大：标题 46px、钱包数值 28px、灵草图标 64px、法器卡片与文字同步放大。
- 场景增加光晕、层次与卡片悬浮效果；灵草园改为五等分，不再出现第五张卡片被拉宽。
- 修复了一个实际视觉问题：旧样式 `width:130px` 会把新建筑卡片压窄，导致名称竖排；现已设为自适应宽度。
