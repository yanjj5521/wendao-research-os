## 澄清一个高频困惑："浏览器能注册，系统里注册不行"

### 根因

程序里的 **同行会页 = 你这台电脑自带的中心实例**（每个安装各有一个独立的
中心数据库与实例 ID）。管理员发来的邀请码属于**管理员的中心实例**——
两边是两个实例，邀请码互不相通：

- 用**浏览器**打开 `http://<管理员IP>:5050/register?invite=…` → 命中管理员的
  中心 → 注册成功 ✅
- 在**程序里的同行会页**用同一个邀请码注册 → 命中的是你本机的中心 →
  报"邀请码不存在或已失效（中心实例 XXXX）" ❌

这不是故障，是"数据主权"设计：每个人的程序自带一个完整中心，加入别人的团队
走的是**同步连接**（中心地址 + API Token），而不是把自己并入对方的实例。

### 正确的成员加入流程（浏览器 + 程序各司其职）

1. **用浏览器**打开管理员发的注册链接（`http://<管理员IP>:5050/register?invite=…`），
   在**管理员的中心**完成注册并**登录**；
2. 登录后进入 **我的联机主页**，复制 **API Token**；
3. 回到程序：同行会页 → **连接同行会** → 填中心地址
   （`http://<管理员IP>:5050`）+ Token → 保存并连接。之后论坛/资料卡/聊天
   自动同步到你的程序里。

### 本版改进：报错页就地给出正确路径

在程序内用外来邀请码注册失败时，报错信息会自动追加（仅个人端内嵌场景显示）：

> 提示：你当前打开的是本机自带的中心实例（每个安装各有一个）。如果这条邀请码来自
> 管理员发的链接，请：① 用浏览器打开管理员发的链接，在管理员的中心完成注册并登录；
> ② 进入「我的联机主页」复制 API Token；③ 回到程序「连接同行会」保存中心地址与
> Token 即可加入。

独立部署的中心（管理员的服务器）不受影响、不显示该提示。
