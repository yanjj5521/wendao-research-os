发布日期：2026-10-29

## 下载哪一个

| 你是 | 下载 | 用途 |
| --- | --- | --- |
| 普通用户 | `WendaoResearch-v1.3.2-User.zip` | 解压后双击 `WendaoResearchV3.exe`，无需 Python |

已经在用 1.3.1 的用户可以在应用内直接更新，不必手动下载。

## 本版变更

### 启动时静默检查新版本

- 程序启动后延迟数秒，查询一次 GitHub 正式发布，**只取版本号，不下载任何内容**。
- 12 小时内最多查一次，避免频繁请求与 GitHub 限流；失败时静默跳过，不影响启动。
- 可在「设置 → 版本更新」关闭：`启动时静默检查新版本（只查版本号，不下载）`。
- 查询只访问公开的 GitHub 发布页，不上传任何本地资料。

### 侧栏提示

- 发现新版本时，“同行会”旁出现一个红点，悬停显示 `发现新版本 vX.Y.Z`。
- 红点只是提示；安装仍需在「同行会 → 更新与同步」手动确认，不会自动替换程序。
- 升级到新版本后，红点会随下一次检查自动消失。

### 修复

- 设置页的趣味层开关读取了旧默认值，导致新库中开关显示为关闭但导航已显示趣味层；现已统一为“开启”。
- 设置页新增的版本更新开关与 `github_auto_check` 设置项联动。

## 升级注意

- 数据目录不变：安装版仍是 `%LOCALAPPDATA%\WendaoResearchV3`；更新只替换 EXE。
- 1.3.1 用户可由应用内 GitHub 通道直接升级；1.3.0 及更早版本仍需手动下载一次。
