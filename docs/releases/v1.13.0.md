# 问道科研 1.13.0

发布日期：2026-11-17

本版把「SPECS 方法 → 碳水泥」八篇文献的阅读规范**内置为系统功能**：侧栏「研究 → 阅读计划」（`/reading/plan`），三遍读工作台同步联动。

## 一、阅读计划（内置你的规范原文）

- **01—08 顺序清单**：每篇的「阅读任务」「目标与交付物」按清单原文入库，系统只提供结构，不预判结论；
- **三条红线常驻**：页面顶部与三遍读工作台都会显示——
  1. 不要直接把拟合时间常数等同于孔径；
  2. 未统一质量或体积基准时，不比较性能；
- **阶段验收自动判定**：
  - 阶段 1（01–03）：能说明 SPECS 测什么、怎样拟合、参数解释依赖什么假设；
  - 阶段 2（04–06）：能比较各版本并提出适用目标材料的测试与建模方案；
  - 阶段 3（07–08）：能区分导电网络、可达孔隙与离子输运，提出有对照实验的研究问题。
  每阶段进度条自动计算（条目=已交付 且 五栏记录齐全），三个阶段各自独立显示。

## 二、与三遍读工作台打通

- 每条计划可一键「建档并开始」：自动在论文三遍读工作台创建同名论文，三遍字段、统一记录、随手记共用同一份记录；
- 已有论文也可关联；三遍读页顶部新增计划提醒条（当前阶段 + 两条红线）。

## 三、每篇统一记录（五栏）

对应你的"每篇统一记录"模板，逐篇可填、自动保存：

1. 研究问题与一句话结论（附原文页码、图号）
2. 样品、装置、测试条件和数据处理流程
3. 关键公式：符号、单位、假设、拟合范围
4. 最有说服力的两项证据，以及一项未解决的问题
5. 对碳水泥体系可迁移的内容、需要重做的验证

## 四、随手记：要点 / 心得 / 问题

阅读中随想随记（选论文 + 类型 + 一句话）：

- 系统按论文与类型自动归档，时间倒序展示；
- 所有「问题」自动汇总为**待解决问题清单**——回答一篇的问题前，先看它是否已在别篇出现。

## 五、数据与升级

- 个人库 **v8 → v9**：新增 `reading_plans` / `reading_plan_items` / `reading_notes` 三张表，
  `reading_works` 增加 `unified_json`、`plan_item_id` 两列；迁移前自动快照；
- 计划内容为内置种子数据，首次访问自动创建；你的旧三遍读记录不受影响；
- 中心库无变更。

## 七、如实说明

- 计划里的论文需要你自行关联 PDF（上传资料 / 文献精读均可），系统不做自动下载；
- 「已交付」状态由你手动标记，系统只检查"状态=已交付 且 五栏齐全"才算完成，防止空交付；
- 阶段验收判定是**记录完整性**的代理指标，不能代替你对"能说明/能比较"的自评。
