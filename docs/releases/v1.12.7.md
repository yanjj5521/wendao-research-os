| --- | --- | --- |

已有用户可在「设置 → 更新与同步」检查新版本。更新前会验证 SHA-256 并备份数据库。

## 本次更新

- **联机与隐私**：关闭联机后不再自动或手动推送境界；启动时自动推送也遵守“自动同步”开关。切换中心或账号后会重新同步境界，保存并联机成功后会补推一次。
- **下载保护**：并发下载会验证响应范围，并在接收过程中限制每个分段的大小；完整校验成功后才替换已有文件。
- **学习插画与动效**：今日学习和论文三遍读各新增一幅离线矢量插画，以及轻缓的光点动画。系统或应用设置为减少动效时会停止动画。
- **构建和验证**：修复 Python wheel 缺少插画的问题；Windows 使用 Git Bash 检查部署脚本，Linux 同步检查 shell 语法，并为面向 `main` 的 PR 启用验证。自动化不再清除全部历史 Actions 产物。

本版未修改数据库结构；原有数据和设置会保留。管理员可在管理开发包中找到 `app/Team-Update.zip`，上传至同行会版本中心。
