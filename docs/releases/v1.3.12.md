## 本版变更

### 论坛自动刷新

- 论坛页新增 30 秒自动刷新，其他成员的新帖/回复无需手动刷新即可出现。
- 正在输入标题、正文或回复时不会刷新；页面切到后台时也不刷新，避免打断写作。
- 聊天页原有的 20 秒自动刷新保持不变。

### 联机功能验收结果

用管理员 + 两个真实成员账号走完整链路，全部通过：

| 场景 | 结果 |
|---|---|
| 管理员登录、生成邀请码 | 通过 |
| 成员 A/B 用同一邀请码注册 | 通过（大小写混用也可） |
| A 发帖，B 打开论坛 | 标题、正文、作者均可见 |
| B 回复，A 重新打开帖子 | 回复可见 |
| A 发聊天消息，B 打开聊天 | 消息可见；聊天每 20 秒自动刷新 |
| A 给 B 发 3 灵石红包 | B 余额从 12 → 15，市场页显示“来自 alice” |
| A 发起 1 灵木 ↔ 1 灵石交换，B 接受 | 状态 completed，双方资产正确变动 |
| B 修改个人资料 | 显示名称、简介、技能保存成功 |
| 管理员控制台 / 账号 CSV 导出 | 成员列表与 CSV 均正常 |
| 聊天轮询参数 | `data-refresh-seconds=20` |

同时运行：

- `hub_self_test.py`：PASS（健康检查、注册页、中心表结构）。
- `online_integration_test.py`：PASS（保存并连接、初始合并、法器交易、自动同步）。
