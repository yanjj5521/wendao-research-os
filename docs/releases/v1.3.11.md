## 本版变更

### 灵知体系完善

- **形态差异加强**：Lv.3 青叶、Lv.5 灵花、Lv.8 道果、Lv.12 星灵的色调由 8%–12% 提升到 30% 左右，
  并加大尺寸差异；仍只染本体，背景保持透明。
- **形态图鉴**：右键“灵知成长”新增五形态列表，标出当前、已解锁、未解锁。
- **成长档案**：面板显示今日活动数、近 7 天活跃天数、连续活跃天数、累计摸头次数。
- **形态动作**：不同形态的摇动幅度不同（幼芽最稳，星灵最活跃）。
- **存储健壮性**：设置文件改为临时文件 + `os.replace` 原子写入；JSON 损坏时安静回退默认值，不丢其他字段。

### 联机健壮性

- 登录限流桶会定期清理过期 IP，避免长期运行后字典无限增长；登录成功会清空该 IP 的失败计数，
  不会出现“已经成功登录却仍被限流”的情况。
- 登录/注册成功后重建会话（`session.clear()` 后再写入用户），防止会话固定攻击。
- 邀请码注册与成员上限检查放入 `BEGIN IMMEDIATE` 事务，避免并发下突破成员上限。
- 真实验收：管理员登录 → 生成邀请码 → 成员用大小写混用的邀请码注册 → 进入个人页，全部通过。

### 项目精简

- 删除可再生成的发布产物与缓存：`out/`、`deploy-cloud/`、`packaging/generated/`、`core/.runtime/`、
  `.runtime/` 下的验证快照目录。
- 删除未被任何代码引用的旧灵知贴图 `static/pet/lingzhi_assistant.png`。
- **保留** `.runtime/instance/`、`.runtime/storage/` 与 `.runtime/logs/`：源码模式运行时可能含真实数据库、
  备份与凭据，不能按“缓存”删除。
- 仓库体积从约 **539 MB** 降到 **217 MB**（其中 `.venv` 约 200 MB，可按需重建）。
- 需要重新生成安装包时运行：`python tools/build.py --assemble --output out`。

## 升级注意

- 数据目录不变；本版没有数据库结构变更。
- 灵知 `progression` 字段保持兼容，已有等级与形态不会重置。
