# 问道科研 1.8.3

## 内置 Headscale 虚拟专网

- 新增 `native/headnet` 用户态虚拟网络助手，基于 Tailscale `tsnet v1.104.4`，可指定自建 Headscale 的 `ControlURL`。
- 中心端可在程序中一键加入 Headscale，并把同行会发布到 Headscale 分配的虚拟 IP；邀请码链接自动使用该地址。
- 成员端无需安装系统 VPN 网卡：程序通过 Headscale 虚拟网络连接中心，并只在 `127.0.0.1` 建立本地代理入口。
- 支持匹配中心端口、成员预授权密钥、节点名称和中心虚拟 IP/主机名。
- 预授权密钥只保存在本机个人数据库，不进入同步事件、个性化包或发布资产。
- 新增 `deploy/headscale` 自建服务器示例，包含 Headscale v0.29.7、Caddy HTTPS 和嵌入式 DERP/STUN 配置。
- Headscale 控制端必须是成员都能访问的 HTTPS 地址；跨 NAT 场景需要可用的 DERP/STUN 中继。

## 使用前准备

1. 按 `docs/HEADSCALE.md` 部署 Headscale 和 HTTPS 反向代理。
2. 在 Headscale 创建用户和每个成员的预授权密钥。
3. 中心端在程序“Headscale 虚拟专网”中作为中心启动。
4. 成员端填写同一控制端、中心虚拟 IP 和端口，作为成员连接。
5. 点击“打开虚拟网络同行会”，使用邀请码注册或登录。

## 升级说明

- 本版不新增数据库 schema；旧数据目录可直接升级。
- Headscale 预授权密钥不是公共凭据，请勿把密钥写入 README、GitHub、聊天记录或共享截图。
- 成员端第一次使用需要能访问 Headscale 控制端；中心端和成员端都需要网络访问 DERP/STUN。
