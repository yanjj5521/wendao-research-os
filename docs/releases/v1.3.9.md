## 本版新增

### 积分面积计算

- 新页面：实用工作台 → **积分面积计算**，也可从侧栏“研究与输出 → 积分面积”进入。
- 支持 `.txt` / `.csv` / `.tsv` / `.dat` / `.xy` / `.asc` 文本，以及 `.bin` 原始二进制：
  - 文本自动识别逗号、制表符、空格分隔；两列取 x、y，单列按行号作 x；跳过表头与 `#` 注释。
  - 二进制可选 float32/float64/int16/int32/uint16/uint32、大小端、成对 x,y 或单列 y。
- 计算方法：
  - 复合梯形法：`A = Σ (xᵢ₊₁ − xᵢ)(yᵢ + yᵢ₊₁)/2`
  - Simpson 1/3：`A = h/3 · [y₀ + 4Σy_odd + 2Σy_even + yₙ]`，仅在等距且区间数为偶数时可用
- 输出：净面积、绝对面积、正/负面积、数据点数、步长、平均 y、质心 x、均方根 y，
  以及公式、逐步代入过程、曲线与面积示意图、前 8 行数据预览。
- 正负面积按曲线与 `y=0` 的交点精确拆分；自动跳过 NaN/Inf、排序 x、合并重复 x 并给出说明。
- 全程本机计算，不上传云端；上限文本 8 MB、二进制 32 MB、30 万点。

### 管理员凭据文件说明

- 核实：首次创建 admin 账户时会在数据目录生成 `instance/HUB_ADMIN_CREDENTIALS.txt`；
  安装版位于 `%LOCALAPPDATA%\WendaoResearchV3`，便携版位于程序旁 `user_data/`。
- **发布压缩包按设计不包含该文件**，它只在首次运行后生成；改密成功后自动销毁。
- 新增命令 `WendaoResearchV3.exe admin-path`：只显示凭据文件路径与生成状态，不显示密码。
