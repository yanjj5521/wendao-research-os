## 新功能：宠物乐园（漫游桌宠，第一期）

借鉴洛克王国风格的**多桌面宠物系统**。本版交付基础玩法与可扩展架构；捕捉、地图遭遇、
对战等后续玩法的数据结构与公式已预留。

### 基础玩法

- **领养**：首次进入"宠物乐园"初始三选一（焰尾犬/露珠蛙/苔背龟），可起昵称。
- **桌宠显示与待机动画**：一键唤出透明桌面窗口（可拖动、置顶、位置记忆）；呼吸起伏、
  眨眼、尾巴/翅膀摆动、"开心"小跳，饿了/累了会低垂眯眼。
- **基础交互**：单击说话（性格台词）、双击摸头（默契+）、右键菜单：喂食/玩耍/切换宠物/
  安静模式/收回。喂食/玩耍也可在乐园页对任意队员操作；太饱/太累会被拒绝。
- **养成**：饥饿/体力随时间衰减与回复；喂食玩耍加经验，Lv 上限 10，升级有提示。
- **图鉴**：六格图鉴——未遇见只有深色剪影，遇见过显示名字，捕获后解锁描述。

### 为后续预留的扩展结构（本版已就位，UI 未开放）

- **捕捉**：`services/roam_pets/capture.py` —— 三种球（漫游/高级/究极）与完整捕捉公式
  `p = capture_base × 球加成 × (2−hp比) × 稀有度 × 元素加成`，三次摇动判定 `attempt()`；
  `catalog.ELEMENT_CHART` 元素克制表共用。
- **地图**：`maps.py` 四张场景（起始平原已开放，雾语林/焰脊火山/月影湖按等级解锁），
  每图带遭遇表（物种+权重）。
- **对战/交换**：属性面板 `base_stats` 与元素克制已定义。

## 架构（可扩展分层）

```
services/roam_pets/
  models.py    Species/PetState 数据模型（JSON 可序列化）
  catalog.py   物种目录 + 元素克制（加新宠物=加一个条目）
  storage.py   user_config/roam_pets.json 原子读写
  service.py   养成纯函数：adopt/feed/play/tick/dex_view（全部可测）
  capture.py   精灵球公式与摇动判定（预留）
  maps.py      地图与遭遇表（预留）
  frames.py    过程化渲染帧：build_frame(species, t, mood) 纯函数（可测/可截图）
  window.py    透明 Tk 窗口（独立进程，沿灵知桌宠的透明/说话契约）
web/routes/roam.py + templates/roam.html + static/roam.css   宠物乐园页
CLI：WendaoResearchV3.exe run-roam-pet [--species ID]
导航：成长与陪伴 → 宠物乐园（可隐藏）
```

新增物种只需在 `catalog.SPECIES` 加一条定义（palette/shape/台词），渲染、图鉴、捕捉
自动生效。
