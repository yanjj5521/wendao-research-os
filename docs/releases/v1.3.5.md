# 问道科研 1.3.5

发布日期：2026-10-30

## 下载哪一个

| 你是 | 下载 | 用途 |
| --- | --- | --- |
| 普通用户 | `WendaoResearch-v1.3.5-User.zip` | 解压后双击 `WendaoResearchV3.exe`，无需 Python |
| 同行会管理员 / 开发者 | `WendaoResearch-v1.3.5-Admin-Dev.zip` | 上传成员更新、重建程序、查看源码与测试 |

已在 1.3.1 及以上的用户可在应用内直接更新。

## 本版变更

### 提交后回到原位置

- 保存实验、修改筛选条件、切换分页后，页面会回到提交前所在的滚动位置，而不是跳回顶部。
- 表单提交与链接跳转共用同一套记忆：提交时记下位置，落地页在 15 秒内恢复；
  分页链接按目标地址精确匹配，筛选表单按“下一次落地页”恢复。
- 恢复时按页面实际高度夹取，列表变短也不会滚到空白处；恢复使用瞬时定位，不播放平滑滚动。
- 全局搜索框显式排除，搜索结果仍从顶部开始。表单可通过 `data-no-scroll-restore="1"` 自行退出。

### 灵知重新设计

- 背景改为随心情变色的柔光，加一块贴地软阴影；只给灵知自身像素染色，
  透明边角不再出现整块淡色方雾。
- 交互细节：
  - 记住上次位置，重启后回到原处；越界时自动夹回屏幕内。
  - 拖动与单击区分：拖动只移动位置，不再误触发台词；单击仍播报今日进度。
  - 右键可锁定位置，避免误拖；可“安静 30 分钟”；可一键回到右下角。
- 菜单按“查看 → 陪伴 → 显示 → 关闭”重新分组，常用动作更靠前。

### 同行会入口

- 登录页、注册页与同行会各页顶部新增“← 返回系统界面”，点击回到个人端首页。
- 嵌入桌面端时该按钮指向 `/`；独立中心模式默认隐藏，可用
  `RESEARCH_OS_SYSTEM_URL` 指定要返回的系统地址。

### 管理员首次登录凭据

- 首次启动生成的管理员用户名与初始密码，直接显示在同行会登录页顶部的醒目卡片中。
- 只在**主机本机**（127.0.0.1 / ::1）显示，并会再次核对账号是否仍使用该密码；
  远程访问者看不到。
- 修改密码后一次性凭据文件会被销毁，卡片随之消失。

## 升级注意

- 数据目录不变：安装版仍是 `%LOCALAPPDATA%\WendaoResearchV3`；更新只替换 EXE。
- 本版没有数据库结构变更，不需要迁移。
- 1.3.4 及更早版本需要手动安装一次 1.3.5；之后可走应用内更新。
