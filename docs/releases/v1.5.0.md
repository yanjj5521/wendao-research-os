## 五项修改

### 1. “连接同行会 → 只保存”修复与提示强化

- 排查结论：只保存本身能把模式/地址/Token/自动同步写入本机数据库（实测通过）；
  真正让用户觉得“没保存成功”的场景是 **校验失败时输入全部丢失**（如地址填了不支持的
  `ftp://`、或启用联机却没填 Token——此前什么都不存，只报错）。
- `features/sync.py::online_settings_save`：非敏感输入（模式/地址/自动同步）**先落库再校验**；
  校验失败时提示“…**已暂存**你填写的地址与模式，修正后重新保存即可”，输入不再丢失。
- 成功提示保持明确：“已保存（未联机）：中心地址与 Token 已写入本机数据库…” /
  “已保存：联机保持关闭…”；失败提示具体到原因（URL 策略 / 必须填写 Token）。

### 2. 删除同行会“管理员如何建立”段落

- 删除 `hub_templates/admin.html` 中的 `admin-origin` 整段（“管理员来源 · 第一次启动中心时自动创建…”）。
- 清理 `hub_static/hub.css` 中全部 `.admin-origin*` 规则（11 处）与对应响应式媒体查询，
  大括号配平校验通过。
- `hub/routes/admin.py` 移除该模板专用的 `admin_credentials_exists` 上下文变量（凭据路径仍在
  管理页其他位置使用）。

### 3. 本地个性化设置界面美化

- `static/style.css`：设置卡片增加悬浮抬升/描边过渡、图标微缩放与内描边；“模型共享与导入”
  卡片使用金色渐变底与描边突出；网格间距 16→18px。
- 设置页保持既有卡片+图标体系（2 列网格、🤖/🤝 等图标、分组标题），截图验收通过
  （1440px 全页截图，卡片分区清晰、文字可读）。

### 4. 注册信息保留

- 服务端：注册失败的所有回跳都携带 `u/d/e`（用户名/显示名/邮箱）草稿参数，页面自动回填；
  **密码永不进入 URL 或草稿**。
- 浏览器端：`hub_templates/register.html` 的 `localStorage` 草稿（`hub_register_draft_v1`）
  在输入时自动保存，注册窗口关闭/最小化后重开自动恢复；注册成功后自动清除；
  新增“清空草稿”按钮；内联脚本通过 `node --check`。
- `hub/routes/auth.py::register_page` 支持 `?u=&d=&e=` 回填。

### 5. 全局异常恢复 + 模型共享

- 全局异常兜底（`web/runtime.py`）：任何 404/500 错误页均提供 **“🏠 返回主界面”**、
  “重试当前页面”、“返回上一页”，无需重启程序；API 路径返回 JSON。
- 模型共享（`services/ai_provider.py` + `web/routes/settings.py` + `templates/ai_share.html`）：
  - **共享**：设置 → 模型共享与导入 → 生成共享码（可选是否包含访问密钥；含密钥时页面与
    note 均有泄露警示）；
  - **使用他人模型**：粘贴共享码导入为“共享模型记录”，一键启用后论文摘要即调用该接口；
  - **导入自己的 API**：把自己的 OpenAI 兼容接口/Ollama 地址录入为共享模型；
  - **授权与连接**：共享码仅含端点/模型名（密钥默认不含），导入配置只保存在导入者本机、
    **仅限其个人使用**（共享页与设置页均注明）；论文资料不因共享暴露。
