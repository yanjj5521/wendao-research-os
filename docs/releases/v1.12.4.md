## 一、同行会显示修为境界

以前中心只显示"修为"这个数字，看不到处在哪个境界。

- 新增 `realm_label()`：把中心侧累计修为换算成 **练气 / 筑基 / 金丹 / 元婴 / 化神 / 炼虚**，
  阈值与福利额度共用同一套阶梯，不会出现两套标准；
- 中心首页：成员的修为球直接显示境界名，下方给出修为与灵石；
- 同行名册：每位成员显示 `@账号 · 金丹（950 修为）`；
- 我的联机主页：标题下显示「修为 950 · 境界 金丹」；
- 管理台成员表新增 **境界** 列。

修为来自中心侧的 `cultivation` 资产流水，与个人端境界各自独立统计，互不覆盖。

## 二、论文三遍读与汇报工作台（新功能）

侧栏「研究 → 论文三遍读」（`/reading`），把"先抓骨架—再抠细节—最后叙事"做成可填流程。

**三遍阅读，字段对应动作**

| 遍次 | 你要回答 | 系统给什么 |
| --- | --- | --- |
| 第一遍 5–10 分钟 | 五个 C：类型、结论、假设是否合理、贡献、是否清楚 | 读完即可标记「细读 / 存档 / 不读」 |
| 第二遍 约 1 小时 | 一句话说清怎么做、方法总览、数据与对比、结果、局限、与课题关联 | 自动生成文献卡 |
| 第三遍 2–3 小时 | 公式对代码、论文没写的实现细节、能被推翻的情形 | 只在核心文献上做，清单会提示 |

**自动产出**

- **行动清单**：不让你手动打勾，按字段是否填完自动判定五步进度；
- **六段式汇报大纲**：封面 / 背景与动机 / 方法 / 实验结果 / 结论与不足 / 创新点与借鉴价值，
  一键复制成纯文本，直接贴进幻灯片；
- **场景侧重**：组会 / 课堂精读 / 文献综述 / 开题答辩，四种场景给出不同的讲述重点；
- **问答准备**：按「选题价值 / 创新点 / 方法合理性 / 局限性 / 拓展启发」五类留空位，
  提前写关键词，避免现场卡住。

数据存本机 `reading_works` 表，不上传同行会；升级时自动建表（个人库 v6 → v7）。
