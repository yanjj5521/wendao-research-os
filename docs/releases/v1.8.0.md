# 问道科研 1.8.0

发布日期：2026-11-02

## 宠物乐园完整版

- 修复领养后丢档：桌宠窗口不再把 `feed/play` 返回对象误写为整份存档，也不再使用启动时的旧快照覆盖网页端领养结果。
- 存档升级为 v2：跨进程锁、事务更新、原子写入、备份恢复和旧存档兼容。
- 完整单人循环：初始领养、喂食/玩耍/星莓、四张等级地图、野外战斗、元素克制、精灵球捕捉、商店补给、全队休整、队伍切换、图鉴与冒险统计。
- 新增生命值与战斗奖励，宠物成长、同行币和道具完全本地保存，不影响个人科研修为。

## 同行会聊天：表情选择器

- 常用表情收纳到“😊 表情”弹层，点击后展开，不再长期占满聊天区。
- 点击表情会可靠插入到当前光标位置，同时同步 textarea 的输入状态。
- 已验证纯表情消息（如 `😀✨🧪`）可通过 JSON 即时发送、落库并被另一账号增量拉取。

## 恢复本机联机中心控制

个人端“同行会”页面重新提供完整的本机中心控制：

- 未启动：填写端口并“启动联机中心”。
- 已启动：显示局域网地址，可直接“打开联机中心”或“停止中心”。
- 仍保留“进入同行会”，用于在同一程序内打开 Hub。

## 聊天脚本可靠性

- 修复 Hub 布局缺少 `{% block scripts %}`，导致聊天、论坛刷新和注册草稿脚本从未输出。
- 聊天、论坛、注册脚本全部外置为同源静态文件，符合 Hub 的 `script-src 'self'` CSP，不再被浏览器拦截。

## 左侧导航保持原位

- 页面内容与左侧导航都保存滚动位置。
- 侧栏恢复改为布局后多次钳制恢复，并监听 bfcache 的 `pageshow`，避免第一次恢复被布局夹回顶部。

## Hub 文案瘦身

- 移除登录、注册、主页、聊天、论坛、坊市、个人主页、名册、资料、版本和管理控制台中的宣传性、解释性长段落。
- 操作标签、权限限制、错误提示和安全警告保留。
- 被移出的文案统一归档到 `docs/HUB_UI_COPY.md`。
