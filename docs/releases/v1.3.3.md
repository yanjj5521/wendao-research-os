# 问道科研 1.3.3

发布日期：2026-10-30

## 下载哪一个

| 你是 | 下载 | 用途 |
| --- | --- | --- |
| 普通用户 | `WendaoResearch-v1.3.3-User.zip` | 解压后双击 `WendaoResearchV3.exe`，无需 Python |
| 同行会管理员 / 开发者 | `WendaoResearch-v1.3.3-Admin-Dev.zip` | 上传成员更新、重建程序、查看源码与测试 |

已在 1.3.1 / 1.3.2 的用户可在应用内直接更新。

## 本版变更

### 更新包支持断点续传

- 下载中断后不再从零开始：保留 `.part` 与同名描述文件，下次点击继续用 Range 请求续传。
- 服务器不支持 Range（返回 200）时自动改为整包重下，不会拼接出损坏文件。
- 续传完成后仍以发布方 SHA-256 为准；校验失败会删除损坏的部分文件，避免死循环。
- 同行会推送与 GitHub 直连**共用同一套下载器**，两条通道同时受益。
- 中断提示会说明“已保留进度，可重试续传”，不再让人以为要重新下载 60 MB。

### 侧栏提示兜底

- 除了“同行会”导航项旁的红点，侧栏底部新增一条“发现新版本 vX.Y.Z · 去更新”。
- 即使用户把“同行会”从导航里收起，更新提示仍然可见。

### 一致性

- 新增 `services/download.py`，`team_update.py` 与 `github_update.py` 不再各自实现下载循环。
- 下载器的 500 MB 上限、`User-Agent`、超时与错误文案统一。

## 升级注意

- 数据目录不变：安装版仍是 `%LOCALAPPDATA%\WendaoResearchV3`；更新只替换 EXE。
- 1.3.2 及更早版本需要手动安装一次 1.3.3；之后可走应用内更新。
- 若上次下载中断，`storage/team_updates/` 下会保留 `.part` 文件，这是续传依据，不必手动清理。

## 校验

```powershell
Get-FileHash .\WendaoResearch-v1.3.3-User.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```
