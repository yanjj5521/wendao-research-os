# v1.2.0 — 云端门禁与模块化中心

> 发布日期：2026-10-28
> 升级自：v1.1.0
> 数据兼容：schema 仍为 v2，现有数据库无需操作。

## 重点变化

- 联机中心从单文件拆分为 `hub/` 包：应用装配、共享安全层、同步服务和八个领域路由分离。
- 新增云部署访问门禁；公网 `PORT` 模式在缺少 `RESEARCH_OS_ACCESS_CODE` 时 fail-closed，不再静默开放。
- 门禁输入完成 HTML 转义，加入安全响应头、错误尝试限流和非阻塞延迟。
- 上传改为分块写入磁盘并在写入过程中执行大小限制，覆盖知识库、交付、炼丹任务和交付文件夹。
- 中心 API 增加请求体大小上限，并拒绝未知同步事件和超大事件 payload。
- 云端大模型 SDK 固定到可复现版本并加入 SRI 校验；模型选项改为安全 DOM 渲染，界面明确提示内容会发送到云端。
- LAMMPS ZIP 解包增加路径穿越、文件数与解压后总大小限制。

## 打包与维护

- wheel 现在包含 `hub/`、模板、静态资源、桌面宠物资源和 `VERSION`。
- `pyproject.toml` 删除已废弃的 `app`、`db`、`hub_app` 入口，改为当前 `web`/`hub` 结构。
- CI 覆盖 `main` 分支，并检查新的 `hub` 包与 wheel 运行资源。
- README、架构说明和开发命令同步到 1.2.0。

## 验证

- `pytest` 全部通过。
- 个人端基础自检、完整科研链自检、联机中心自检全部通过。
- `run_local.py --self-check` 与 `run_hub.py --self-check` 通过。
- ruff、compileall 与 wheel 资源检查通过。

## 已知边界

- SQLite 仍适合单机和小团队；大规模并发写入应切换到 PostgreSQL。
- 云端托管必须提供持久磁盘；否则本地 `.runtime` 中的数据库与附件可能随实例重建丢失。
