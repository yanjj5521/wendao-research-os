# 同行会界面文案归档

本文件保存从同行会界面移出的解释性、宣传性长文案。界面只保留操作必需文字；需要查看更多说明时查阅本文件。

## 通用布局

- 原品牌副标题：问道科研内置模块 · 资料留在个人电脑
- 原页脚：科研系统同行会 v（版本） · 中心只保存账号、公开主页、公开交流与虚拟资产；科研原文件始终留在个人电脑。

## 登录

- 把科研伙伴连起来，不把私人资料搬上云。
- 账号、个人主页、灵石、法器、个性化和版本更新在这里同步；论文、实验数据、笔记图片仍保存在每个人自己的科研系统中。
- 邀请制注册；一人可保留多个账号并随时切换；同步事件幂等处理；数据库自动备份。
- 社区约定：论坛沉淀问题 · 聊天保持短沟通 · 坊市只流转虚拟资产。
- 登录无响应或页面已过期？先刷新，或清除登录状态后重试。

## 注册

- 同行会是邀请制的小圈子：资料卡与论坛对成员公开；科研原文件永远留在各自电脑，中心只沉淀名片、讨论与虚拟资产。
- 邀请码可直接粘贴管理员发来的注册链接，系统会自动提取。
- 用户名使用英文、数字、下划线；邮箱可选，用于管理员联系。
- 社区约定：论坛沉淀问题、聊天保持短沟通、坊市只流转虚拟资产。注册即表示接受这三条。
- 管理员账号由首次启动自动创建；忘记密码时使用 `WendaoResearchV3.exe admin-path` 查看凭据文件。

## 主页

- 管理员：你负责成员、邀请、版本与中心安全；个人科研资料仍留在每位成员自己的电脑。
- 成员：论坛用于沉淀问题，聊天只处理短沟通，坊市只流转虚拟资产；不让社交打断真正的学习。
- 为什么不共享文件？科研文件大、敏感且容易冲突。共享“资料卡和链接”比同步原文件更稳妥；需要协作的文件再用 Git、共享盘或专门仓库。

## 聊天

- 适合约时间、问一句短问题或给同伴鼓励；需要沉淀的讨论请发到论坛。
- 还没有消息。可以从一句“今天读到哪一张图了？”开始。
- 发送后立即显示。

## 论坛

- 用帖子留下一个问题、一种方法或一条经过你判断的线索；私人原始资料不上传。
- 让别人知道你究竟想弄清什么。
- 标题示例：这张 EIS 图的低频尾部该如何解释？
- 内容示例：说明背景、你已看到的证据、真正卡住的地方，以及希望别人如何帮助。
- 还没有帖子。第一个帖子不必宏大，只要是一个值得同行共同想清楚的问题。

## 坊市

- 红包分“指定红包”和“群发红包”：指定红包立即到账，群发红包 24 小时内可抢，发送者本人也能参与。
- 修为仅是同行会内的虚拟资产，不改变任何人的本地真实进度。
- 指定红包：指定一位成员，立即到账。
- 群发红包：全群可抢，24 小时，自己也能抢；抢到即入账。
- 交换：成交时才同时扣除双方资产。
- 还没有群红包。发一个，让同行沾点喜气。

## 我的联机主页

- 本页是中心权威副本；本地节点连接后可以推送和拉取。
- 在你自己的科研系统“联网通道”页面粘贴此 Token。它等同密码，不要发给其他人。
- 发布资料卡只共享线索，不上传原文件。

## 成员、资料与版本

- 同行名册展示会什么、能做到什么程度；不展示私人文件。
- 资料驿站只共享线索，不复制原文件。成员发布论文、数据源、工具或案例的资料卡；需要原文件时再与发布者单独协作。
- 版本中心：下载新版本到新文件夹，再迁移个人数据库和个性化；不要覆盖正在使用的目录。

## Headscale 虚拟专网

- 中心端和成员端都使用程序内置的用户态虚拟网络助手；中心发布后，邀请码会改用 Headscale 分配的虚拟 IP。
- 成员不用处在同一个 Wi-Fi，也不需要安装系统 VPN 网卡；Headscale 控制端和 DERP/STUN 需要管理员自建。
- 预授权密钥只保存在本机数据库，不进入同步事件、个性化包或发布资产。

## 管理控制台

- 只管理成员、邀请、备份和版本包。成员电脑中的论文、实验、数据集与附件不进入中心。
- SQLite 只由中心主机进程访问，启用 WAL 与 10 秒忙等待。
- 启动时与每 24 小时使用 SQLite Backup API 备份，保留 14 份。
- 公网必须使用 HTTPS；中心 5050 端口不直接暴露。
- 版本更新安装到新目录，不原地覆盖。
- 账号留存：中心数据库 + 每日备份 + 账号 CSV 导出，三重可追溯。
- 注册地址只需指向同一个中心实例，可以是有线、无线或 VPN 地址；指向另一台主机、另一份数据库或另一个端口上的中心时，邀请码会提示“不存在”。
- Tailscale/WireGuard 等 VPN 通常使用 10.x 或 100.64.x 地址；跨局域网时所有成员必须先加入同一个虚拟网络，并允许中心 TCP 端口访问。
- 新邀请码为 10 位大写字母/数字（不含 I/O/0/1）；旧码继续有效。注册页可直接粘贴整条注册链接，系统会自动提取邀请码。
- 福利限制：只可赠与其他活跃成员。单次修为≤60、灵石≤50、每种材料≤6；同一成员每天最多 3 次，累计修为≤120、灵石≤100、各材料≤12。
- 权限矩阵：成员可使用论坛、聊天、坊市、资料卡、自己的主页与头像；管理员额外拥有邀请码、账号启停、头像重置、福利发放、版本发布、数据库备份、账号 CSV 导出、审计日志。
- 全部管理动作写入审计日志（含来源 IP）；成员无法访问任何 `/admin/*` 与导出端点。
