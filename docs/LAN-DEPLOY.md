# 同办公室局域网部署：用你自己的电脑当服务器

> 适用版本：1.9.2 起。**同一办公室的同事不需要 VPN、不需要域名、不需要云服务器**——
> 程序内置的"本机同行会中心"就是为这个场景设计的，全部配置由程序自动完成。

## 什么时候用这套方案

| 场景 | 方案 |
| --- | --- |
| 同一办公室，同事电脑连的**同一个路由器/交换机**（含有线+无线） | ✅ 本文档（最简单，5 分钟） |
| 办公室划分了多个网段，但网段之间可以互 ping | ✅ 本文档（中心机会列出每个网段的入口） |
| 路由器开启了 AP/客户端隔离，同事之间互相 ping 不通 | ⚠️ 先让网管关闭隔离；做不到再走 Headscale（见文末） |
| 同事在家/出差，跨公网访问 | ❌ 用 Headscale 虚拟专网（`docs/HEADSCALE.md`） |

## 一、服务端（你，管理员）—— 共 3 步

### 第 1 步：运行程序并启动中心

1. 双击 `WendaoResearchV3.exe`（和你平时用的一样）；
2. 打开 **同行会** 页；
3. 点击 **"启动本机同行会中心"**。

程序会自动完成：

- 在 `0.0.0.0:5050` 监听（接受任何网卡的连接）；
- 自动发现本机所有可用的局域网 IP，按有线/无线/VPN 分类；
- 把最佳成员入口写入中心配置，之后的邀请码链接自动带上它。

成功后页面会列出形如这样的入口（多网卡会列多条，用**有线局域网**那条）：

```text
http://192.168.1.20:5050      有线局域网
http://192.168.0.35:5050      无线局域网
```

### 第 2 步：放行 Windows 防火墙（仅一次）

首次启动时 Windows 会弹出防火墙提示——**勾选"专用网络"并点击"允许访问"**。

如果之前不小心点了取消，用管理员 PowerShell 执行一次（命令里的路径换成你的 EXE 路径）：

```powershell
netsh advfirewall firewall add rule name="WendaoResearch 同行会中心" dir=in action=allow program="C:\path\to\WendaoResearchV3.exe" enable=yes
```

### 第 3 步：建邀请码，把链接发给同事

1. 同行会页 → 管理控制台 → **邀请码** → 生成；
2. 点邀请码旁的 **"打开注册页"**，复制弹出的完整链接（形如
   `http://192.168.1.20:5050/register?invite=XXXX`）发到同事群里。

> 链接里已经带着你的局域网 IP，同事点开就是注册页，不需要手填地址。

## 二、成员端（同事）—— 共 2 步

1. 解压**同版本**的 `WendaoResearch-…-User.zip`，双击 `WendaoResearchV3.exe`；
2. 打开 **同行会** 页：粘贴管理员发的注册链接（或手填中心地址 `http://192.168.1.20:5050`
   + 邀请码）→ 注册 → 登录，之后正常使用论坛/资料卡/聊天。

成员访问的永远是 `http://<你的IP>:5050`，所有数据都保存在**你的电脑**上；
同事的电脑只存自己的登录状态，卸载不影响团队数据。

## 三、日常维护（建议 3 件小事）

| 事项 | 做法 | 原因 |
| --- | --- | --- |
| 固定你的 IP | 路由器后台 → DHCP 静态绑定你的电脑 MAC → 固定 IP（如 `192.168.1.20`） | 你的 IP 变了，成员要重新填地址 |
| 多网段固定入口 | 管理控制台 → **成员连接地址** → 填入主用入口 | 程序优先使用它，不再随网卡顺序漂移 |
| 数据备份 | 管理控制台 → 备份（数据都在中心电脑上） | 中心电脑就是全团队的数据库 |

开机后只需：双击 EXE → 同行会 → 启动中心（一条点击）。想让它开机自动启动，
可以把 EXE 的快捷方式放进 `shell:startup`（启动文件夹），程序会记住窗口设置。

## 四、常见故障

| 现象 | 处理 |
| --- | --- |
| 成员打不开 `http://<IP>:5050` | ① 中心页确认"运行中"；② 防火墙规则（见第 2 步）；③ 同一网段先 `ping <IP>` |
| 能 ping 通但页面超时 | 杀毒软件的"网络防护"拦截了 EXE 监听，把程序加入白名单 |
| 同事 ping 不通任何主机 | 路由器开了 AP/客户端隔离 → 找网管关闭，或改用 Headscale |
| 你的 IP 变了 | 成员页重新填新地址；或按"固定 IP"一次性解决 |
| 端口 5050 被占用 | 中心启动会明确报错；关掉占用程序，或用管理控制台改端口 |

## 五、以后要跨办公室/在家办公怎么办

同一套程序已内置 Headscale 用户态虚拟专网（无需公网 IP、无需域名、无需安装系统 VPN）：
按 `docs/HEADSCALE.md` 的路径 B（纯内网自签）部署一个中心服务，或先用本文的局域网模式，
扩展时再叠加。两者可共存——局域网入口与 VPN 入口会同时列在成员页。
