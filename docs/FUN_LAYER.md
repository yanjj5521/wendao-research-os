# 趣味层设计约束与内容清单（1.2.0）

> 趣味层 = 洞府（游戏世界）、炼丹、休闲空间、成就、灵宠。
> 自 1.2.0 起默认打开（v3 迁移），设置页可随时关闭；关闭只隐藏入口，不删任何数据。

## 一、设计约束（五条铁律，新增内容前先对照）

1. **只映射，不替代**：所有数值来自真实学习行为——任务交付、复盘卡片、证据闸门、学习条目。不存在"点一下就变强"的路径，也不存在真实货币。
2. **有上限**：领域成长分封顶 100、灵草七阶段封顶、法器等级有 max_level、建筑成本随等级递增（`base_cost × (level+1)`）。奖励仅在任务**首次交付**时结算一次，无重复领取路径。
3. **不打断**：趣味层永远不弹窗打断工作流。回响铃只做"克制的提醒"；灵宠有安静模式且默认低干扰。
4. **可退出**：设置页一键整体关闭；关闭后隐藏四个入口（成就/炼丹/洞府/休闲），数据保留，重新打开即恢复。
5. **语义一致**：修仙叙事必须映射真实科研动作（见下表）。新内容若映射不出真实动作，就不要加。

## 二、材料语义

| 材料 | 语义 | 来源 |
| --- | --- | --- |
| 灵木 ⌁ | 文献与概念 | 阅读、笔记、综述类任务 |
| 玄铁 ⬢ | 实验与硬件 | 实验、电化学、压片、COMSOL 仿真类任务 |
| 星砂 ✦ | 计算与数据 | MD/LAMMPS、ML、数据集、代码类任务 |
| 灵石 ◆ | 通用货币 | 所有任务交付（按 XP 换算） |

判定由 `services/economy.py::MATERIAL_KEYWORDS` 关键词表驱动（按任务标题/类别匹配，未命中默认灵木）。扩充词表即可支持新领域，不需要改代码结构。

## 四、建筑与灵草

- **建筑**（藏经阁/炼丹房/炼器坊/灵植园）：分别对应文献笔记、结构化数据、可复现代码、特殊任务产出四类资产，升级消耗对应材料。
- **灵草七阶段**（种子→破土→幼苗→展叶→含苞→灵花→道果）：生长值 = 领域内学习条目×5 + 计划任务完成×12 + 每日任务×8 + 关键词任务×4 + 加分，**封顶 100**。

## 六、红线（永远不做）

- 不做排行榜、不做每日签到强迫、不做限时逼肝活动。
- 不让任何趣味数值影响真实科研数据的读写。
- 不在趣味层收集或上传任何个人科研内容。
