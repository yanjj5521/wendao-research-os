问道科研 1.3.3
================

唯一入口：
  WendaoResearchV3.exe

  install    安装到当前用户目录，并创建桌面与开始菜单图标
  shortcut   只重建快捷方式
  diagnose   自检并输出诊断信息
  version    显示版本与数据目录
  --mode team 启动同行会中心

普通使用：
  双击 WendaoResearchV3.exe。程序使用独立桌面窗口，不打开外部浏览器标签。
  需要安装图标时，在该 EXE 所在目录打开终端并运行：
      WendaoResearchV3.exe install
  不想自动启动可加 --no-launch。

同行会：
  在问道科研左侧导航点击“同行会”，页面始终在当前桌面窗口内打开。
  管理员在“同行会 → 启动本机同行会中心”点击一次即可托管，默认端口 5050。
  登录后系统按身份显示管理员控制台或普通成员界面，无需第二个 EXE 或 CMD。
  需要独立窗口时可运行：WendaoResearchV3.exe --mode team

更新：
  连接同行会后，在“同行会 → 更新与同步”检查新版本。
  更新只替换程序 EXE；会先校验 SHA-256、备份数据库并保留旧 EXE 以便回滚。
  数据目录不会随更新改变，也不要手工把数据库放进程序安装目录。

兼容：
  首次启动会识别早期 wendao-v3-clean.db，并通过一致性备份迁移。
  如果 5000 端口被旧版或其他程序占用，新版会自动使用 5001 起的空闲端口。

数据：
  安装版：%LOCALAPPDATA%\WendaoResearchV3。
  便携包：本包含 portable.flag，数据保存在同目录 user_data。
  单独下载 EXE：数据同样保存在 %LOCALAPPDATA%\WendaoResearchV3。
  运行 WendaoResearchV3.exe version 可查看当前实际数据目录。

备份：
  个人导出、知识库和完整备份统一在“系统设置与备份”。
  同行会中心只保存账号、公开主页、公开交流与虚拟资产，不同步论文原文件或私人附件。
